# stuyaviators.github.io
Website for StuyAviators, Stuyvesant High School's official aviation club.

## Credits

Parts of this site are adapted from the `recode` branch by **webcubed**: the `Stagger`
entrance animation, the hide-on-scroll header logic, the contact and copy-to-clipboard
behavior, the markdown renderer, the confirm dialog, the form field, and the newsletter
builder (now `/dashboard/newsletter`). Each port is credited in its commit message and in the
source file it lives in. See `docs/recode-port.md` for what was ported, changed or skipped.
